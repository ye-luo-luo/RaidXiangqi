# 突袭匈汉象棋（Demo）

一个融合中国象棋与国际象棋元素、并加入独特 **「突袭 / 夹击」** 机制的棋类变体。
纯前端实现 —— **打开即玩**，电脑 / 手机 / 平板通用，无需安装、无需构建。

---

## ✨ 功能

| 分类 | 内容 |
|---|---|
| 对局 | 双人对战 / 人机对战、悔棋（`U`）、翻转棋盘（`F`，180° 镜像）、新局（`N`） |
| 复盘 | 终局结算界面 + 着法回放（播放/暂停、0.25–8 秒每步、拖动进度条跳转） |
| 联机 | 互联网直连（联机码）或局域网自建中继；连接后**实时选择执子与赛制**、多局赛制**相邻两局换边**、悔棋申请、认输、求和、**延时（ping）显示**、**脱机自动检测** |
| 规则 | 认输开局 10 步后解锁、求和开局 20 步后解锁；赛制「一锤定音 / 事不过三」；比分格式 `红X：平Y：黑Z` |

## 🚀 怎么玩

### 方式一：单文件版（推荐分享）

把 `单文件版/突袭匈汉象棋-v1.00.006.html` 这一个文件发给对方（微信 / AirDrop / 蓝牙 / U 盘），
用浏览器打开即可。本地对局、人机、悔棋、回放全部可用。

### 方式二：多文件版（本地 / 部署）

打开 `多文件版/index.html`；或本地起个静态服务器：

```bash
cd 多文件版
npx serve .
# 或 python -m http.server 8000
```

### 方式三：局域网联机（最稳，零外网依赖）

电脑运行：

```bash
node 多文件版/server.js          # 默认端口 8644，也可 node 多文件版/server.js 9000
```

两台设备连**同一 Wi-Fi**，都打开 `http://<电脑IP>:8644/`，
一方点 `🌐 联机` →「局域网联机」→ `创建联机码`，另一方输入该码加入。

### 方式四：互联网联机（需联网）

双方打开游戏 → `🌐 联机` →「互联网联机」，一方 `创建联机码` 并把 6 位码发给对方，另一方输入该码加入。

> **连不上时**：该模式依赖两个外部服务 —— CDN 上的 PeerJS 库 + PeerJS 公共信令云 `0.peerjs.com`。
> 任一不可达就连不上（此时联机码**不会**显示，界面会直接说明原因）。三种处理方式：
>
> 1. **改用「局域网联机」**（推荐）；
> 2. **自建信令服务器**：`npx peerjs --port 9000`，把 `主机:端口`（如 `192.168.1.5:9000`）填进
>    「互联网联机」面板的输入框（留空则走公共云）；也支持 `https://host:port/path`；
> 3. 换网络 / 挂代理后重试。

## 📖 规则要点

- 棋盘 **11×12**，坐标原点左下角：x 0–10、y 0–11；河界在 y=5 与 y=6 之间；
  九宫（米字格）在下方 (4,1)–(6,3)，上方与之对称。
- **汉军（红）居下先行，匈军（黑）居上**。匈方异名：兵→卒、炮→砲、相→都、士→氏、皇→单、檑→礌，
  其余（車馬突袭）同名。
- 传统棋子走法同中国象棋：車 / 馬 / 相 / 士 / 皇 / 炮 / 兵（含九宫、飞将、蹩马腿、塞象眼、炮架、兵过河）。
- **檑 / 礌**：八方向走任意空格；只能吃紧邻八格内「落单」的敌子
  （以判定的檑为中心 3×3 邻域内，该敌子的正邻——共享边，斜角不算——无任何棋子）。
- **突**（走斜线）/ **袭**（走直线）：可越过己方棋子、不可越过敌方棋子、不落点吃子；靠 **夹击** 吃子：
  - **直夹**（供突）：己-敌-己 同行或同列，翼子与被夹击敌子紧邻一格（中间无空格）；
  - **斜夹**（供袭）：己-敌-己 同斜线，翼子与被夹击敌子紧邻一格（中间无空格）；
  - 夹击完成 **当回合不能吃**，自下一回合起可「突袭」：该棋子移动到被吃子位置将其吃掉；
  - 被夹击的敌子（格上显示 ⚡）**仍可自由移动**（不存在钳制/定身），只是有被突袭吃掉的风险。
- **胜负**：将死对方，或直接吃掉对方王（皇/单）即获胜；困毙（无子可动）或三次重复局面判和。

> 完整规则也可以在游戏内点「📜 规则」查看。
