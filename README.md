# 突袭匈汉象棋 1.0（Demo）

一个基于 `结构.json` 实现的棋类变体 **突袭匈汉象棋**，纯前端单页应用：
打开 `多文件版/index.html` 即可玩，手机、电脑均可（无需联网、无需构建）。
同一份代码打两版，分目录存放：

- **多文件版/**：`index.html` + `css/` + `js/` + `server.js`（源码版，便于阅读/修改）
- **单文件版/**：全部内联进一个 html（自包含，发给手机/上传最方便）

## 运行方式

- **最简单**：打开 `多文件版/index.html`，或带版本号的入口（如 `多文件版/突袭匈汉象棋-v1.00.005.html`，由构建脚本同步生成，共享 css/js）用浏览器打开。
- 或本地起一个静态服务器，例如：
  ```bash
  cd 象棋1.0/多文件版
  npx serve .
  # 或 python -m http.server 8000
  ```
  然后浏览器访问对应地址（手机上可用局域网 IP 访问，同屏轮流执子或开人机）。
- **联机对战（局域网/本机）**：
  ```bash
  cd 象棋1.0/多文件版
  node server.js            # 默认端口 8644，可传端口参数或设 PORT
  ```
  两台设备连同一 Wi-Fi，打开 `http://<电脑IP>:8644`，一方点 `🌐 联机` →
  「局域网联机」→ `创建联机码`，另一方输入该码加入。也可在公网机器上部署
  `server.js` 实现互联网联机（零依赖，长轮询，无 WebSocket）。

## 玩法与操作

- 点击/点按本方棋子 → 高亮可走点：**绿点**=移动、**红圈**=吃子、**橙闪圈**=突袭吃子。
- 点击落子。⚡ 标记 = 正被敌方**夹击**的棋子（可被突/袭“突袭”吃掉，仍可自由移动）。
- 按钮：`新局`、`悔棋`、`翻转`（棋盘 180° 镜像，含九宫/河界文字）、`回放`、`认输`（开局 10 步后可用）、`求和`（联机中开局 20 步后向对方提和棋认定）、`规则`、`人机对战`（可勾选 AI 执红）、`🌐 联机`。
- 快捷键：`N` 新局、`U` 悔棋、`F` 翻转。
- 版本号 `x.xx.xxx`（大版本.小版本.修改版本）显示在页面头部，修改功能后需递增并同步到单文件版。

## 联机对战

通过**分享一个联机码**实现双人异机对战，两种方式（`🌐 联机` 弹窗内切换）：

1. **互联网联机（PeerJS）**：无服务器，浏览器联网即可跨网络直连。房主点
   「创建联机码」得到 6 位码发给对方，对方在「互联网联机」输入该码加入。
   *需要能访问公共 CDN 加载 PeerJS 库。*
2. **局域网联机（自带中继）**：运行 `node server.js` 后两台设备打开同一地址，
   同样「创建联机码 / 输入联机码」配对。无需外网，零依赖。

**执子与赛制（连接后实时选择）**：连接建立后进入对局大厅，双方各自实时选择执红（汉）/ 执黑（匈）
与赛制——**一方改动，另一方立即刷新**；执子一致时首次由系统随机分配，之后重复同色直接**复用上次结果**
（不再反复洗牌）；**赛制由房主选择**（`一锤定音` / `事不过三` 三局两胜，平局自动加赛），加入方仅可查看。
加入方点「**准备**」、房主点「**开始对局**」后双方同时开局。**多局赛制中相邻两局执棋相反**（先手互换）。
大厅实时显示网络**延时（ping，毫秒）**，并<b>时刻检测对方是否脱机</b>（每 2 秒心跳，连续约 8 秒无回应自动断开）；联机中仍可打开联机界面，随时「**断开**」，断开后可再次联机。
**认输在开局 10 步之后解锁**；联机「**求和**」（和棋认定）在**开局 20 步之后**解锁，对方同意即和棋加赛。
比分格式为 **`红X：平Y：黑Z`**（中间为平局数），实时显示。

**联机悔棋**：一步 = 一个着法（与对方是否落子无关）。悔棋时若对方悔棋次数 ≤ 自己，
需提交申请、对方同意后双方各回退一步，且**对方获得一次免同意悔棋机会**；对方悔棋次数
多于自己时可直接悔（免同意）；有免同意机会时优先消耗（不叠加，杜绝“多次免同意”）。

**认输 / 求和**：认输（本方认负、对方获胜）在**开局 10 步之后**解锁；联机中「求和」向对方
提出和棋认定（**开局 20 步之后**解锁），对方同意即和棋（加赛一局）。

联机中每步着法实时同步、双方各自校验合法性；终局双方都会弹出结算界面（含比分与
赛制状态），任一方「下一局 / 重新开始比赛」即同时同步重开。联机中禁用 `新局`/`人机`，
断开后自动回到本地模式。

## 规则要点（依结构.json）

- 棋盘 11×12，坐标原点左下角：x 0–10、y 0–11；河界在 y=5 与 y=6 之间；九宫（米字格）在下方 (4,1)–(6,3)，上方与之对称。
- **汉（红）居下先行，匈（黑）居上**。匈方异名：兵→卒、炮→砲、相→都、士→氏、皇→单、檑→礌，其余（車馬突袭）同名。
- 传统棋子走法同中国象棋：車/馬/相/士/皇/炮/兵（含九宫、飞将、蹩马腿、塞象眼、炮架、兵过河）。
- **檑/礌**：八方向走任意空格；只能吃紧邻八格内“落单”的敌子（以判定的檑为中心、其周围 8 格 3×3 内该敌子的正邻——共享边，斜角不算——无任何棋子）。
- **突**（走斜线）/ **袭**（走直线）：可越过己方、不可越过敌方、不落点吃子；靠**夹击**吃子：
  - **直夹**（供突）：己-敌-己 同行或同列，敌子两侧各 3 格内、中间无子；
  - **斜夹**（供袭）：己-敌-己 同斜线，敌子两侧各 3 格内、中间无子。
  - 夹击完成**当回合不能吃**，自下一回合起可「突袭」：该棋子移动到被吃子位置将其吃掉。
- 胜负：将死对方或直接吃掉对方王获胜；困毙（无子可动）或三次重复局面判和。

## 结算与回放

- 一方获胜或和棋后弹出**结算界面**，给出「重新开始」「回放本局」选项，对局自动锁定（不能再走子）。
- **回放**：按 1 秒/步自动播放双方着法，可播放/暂停、加速/减速（0.25–8 秒/步），并可**拖动进度条**跳转任意步；退出回放后回到实时对局。

## 演示版实现约定（对原文案的解释）

原始规则文本（`结构.json`/规则 PDF）对个别细节存在简写或歧义，本 Demo 采用如下
**明确的实现解释**，并在游戏内“规则”弹窗中同样标注：

1. **夹击不钳制**：被夹击的敌子仍可自由移动（不存在“钳制/定身”机制），只是会被
   对方的突/袭在夹击完成的下一回合起“突袭”吃掉。
2. **夹击范围**：翼子须与被夹击的敌子**紧邻一格（中间无空格）**；成直线为直夹（供突）、
   成斜线为斜夹（供袭），斜夹与直夹互不混用。
3. **胜负**：采用中国象棋式“将军/应将/将死”，同时允许直接吃王取胜（王可被任何
   吃法吃掉）；困毙与三次重复判和。原规则列有“长将/长捉/重复”约定，演示版未做
   禁长将/长捉的裁定，只做三次重复自动判和。
4. **檑 的“落单”**：以判定的檑为中心，其周围 8 格（3×3 邻域，贴边时收缩为 5 格、
   角落为 3 格）内，被吃敌子的**正邻**（共享边/正交相邻，斜角相邻不算）没有任何棋子
   （任意己方/敌方棋子都算，判定的檑本身除外）即为落单；8 格之外的棋子与判定无关。
   檑只能吃紧邻八格内的落单敌子，不可落点吃非落单敌子。

如需调整以上任何约定（例如恢复钳制、改成棋盘翻转默认值等），改 `多文件版/js/logic.js` 中
对应函数即可（详见代码注释）。
